# Medaile – plán stavby

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Síň slávy se změní na obrazovku „Medaile“ s 18 medailemi po kategoriích (10/100/200 správně), bronzovou/stříbrnou/zlatou korunkou za odznaky 100/200/300 a animovanou oslavou nové medaile.

**Architecture:** Počty správných po kategoriích a získané medaile přibudou do uložení (`saveVersion` 4). Čistá logika je v `lib/medals.ts` (medaile) a `lib/celebrations.ts` (fronta oslav: medaile před odznaky). Hook `useGameState` z ní plní frontu. UI přibude: `MedalCelebration` (celá obrazovka, CSS animace) a `MedalsScreen` (nahradí `HallOfFameScreen`).

**Tech Stack:** Vite + React 19 + TypeScript, Tailwind 4, Vitest (prostředí `node`, jen testy logiky), Web Audio.

**Spec:** `docs/superpowers/specs/2026-10-18-medaile-design.md`

## Global Constraints

- Medaile: bronzová **10**, stříbrná **100**, zlatá **200** správně v dané kategorii. Celkem 6 kategorií × 3 = 18.
- Barvy medailí: bronz `#d97706`, stříbro `#cbd5e1`, zlato `#facc15`. Stuha modro-růžová, uprostřed hvězda.
- Odznaky a korunky:

  | Odznak | Podmínka | Odměna |
  |---|---|---|
  | „Pilná školačka“ | 100 správně celkem | Bronzová korunka |
  | „Šikovná počtářka“ | 200 správně celkem | Stříbrná korunka |
  | „Královna počítání“ | 300 správně celkem | Zlatá korunka (`acc-crown`) |
  | „Násobilková hvězda“ | — | nic neodemyká |
- Počítá se každý správně vyřešený příklad, i na další pokus. Přeskočený příklad se nepočítá. Obtížnost nehraje roli.
- Medaile nedávají zlaťáky ani kousky. Získaná medaile ani odznak nezmizí.
- Převod z verzí 1–3: počty jsou 0 a medaile žádné. Kdo má méně než 300 správně celkem, tomu se Zlatá korunka odebere a sundá (jen při převodu). Kdo má 300 a víc, tomu zůstane.
- Fronta oslav je společná, medaile jsou před odznaky. Medaile a odznaky doplněné při načtení, importu nebo resetu se neoslavují.
- Během oslavy stojí stopky Akademie.
- Fanfára je kódem (Web Audio) a respektuje `settings.soundOn`. Animace respektuje `prefers-reduced-motion`.
- Texty:
  - oslava: „Bronzová medaile!“ / „Stříbrná medaile!“ / „Zlatá medaile!“, pod tím „<název kategorie> · <cíl> příkladů správně“, tlačítko „Hurá!“;
  - ukazatel: „do bronzové 6/10“, „do stříbrné 42/100“, „do zlaté 143/200“; po všech třech „Všechny medaile!“;
  - záložka a nadpis: „Medaile“.
- Bez sítě, bez nových závislostí.

## Review Focus

1. **Telefon s uloženou v3, Zlatou korunkou na hlavě a 150 správnými.** Korunka zmizí z vlastněných i z hlavy, Bronzová korunka přibude (Pilná školačka) a nic se neoslavuje. Test je v Task 2, kontrola v prohlížeči v Task 6.
2. **v3 s 320 správnými a korunkou na hlavě.** Korunka zůstane nasazená a přibudou oba nové odznaky i obě nové korunky, bez oslav. Test je v Task 2.
3. **Poškozená v4 data** (`medals` s neznámými id, `correctByTopic` záporné, desetinné nebo chybějící). Výsledek se vyčistí a nespadne. Test je v Task 2.
4. **Jedna odpověď přinese medaili i odznak** (10. násobilka a zároveň 100. celkem). Oslavy přijdou v pořadí medaile → odznak. Test je v Task 4.
5. **Oslava během Akademie.** Další příklad nezačne měřit čas, dokud oslava běží. Kontrola v prohlížeči v Task 5.
